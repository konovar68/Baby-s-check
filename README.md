# Дневник малыша — Android 0.2.0

Локальный дневник одного ребёнка на одном телефоне. Kotlin, Jetpack Compose, Room. Android 8.0 (API 26) и новее. Интернет, аккаунт и сервер не требуются; разрешение INTERNET не запрашивается. Системное облачное резервирование отключено.

## Возможности

- Сон и грудное кормление с таймером, переживающим закрытие приложения. Одна активная сессия; её завершение сохраняет событие.
- Ручные записи: сон, грудь (левая/правая), смесь (мл), подгузник (мочеиспускание/стул/смешанный), прикорм (продукт, граммы, реакция), купание, рост (см), вес (кг).
- Произвольная дата и время, исправление и подтверждаемое ручное удаление.
- Дневная лента, сводка, графики роста и веса. Сон делится по фактическому пересечению с календарным днём, включая переход через полночь. В сводку входят завершённые сессии; активный таймер показан отдельно.
- Профиль с именем и датой рождения.
- JSON-выгрузка всей истории или выбранного дня через системный выбор файла. В дневной файл входят события, **начавшиеся** в выбранный день, включая их окончание на другой день. Профиль включается в оба варианта. Незавершённый таймер не экспортируется: сначала завершите его.
- Импорт с предварительным подсчётом: только новые либо новые + обновление по ID. Обновление заменяет запись целиком данными из файла, независимо от времени изменения. Никаких автоматических удалений. Повторный импорт не создаёт дубликатов.
- Профиль импортируется только по отдельному флажку. Перед заменой событий или профиля сохраняется внутренняя копия `before-import.json`; её можно выгрузить из раздела «Данные». Хранится только последняя такая копия. База обновляется транзакционно.

Импорт предназначен для истории **того же ребёнка**. Совпадение времени/типа у разных ID не считается дублем. Удалённая вручную запись будет добавлена снова, если её ID присутствует в импортируемом файле. Предел импорта — 20 МБ / 100 000 событий. Файл проверяется полностью до изменений.

## Новое в 0.2.0

- График сна за 7/30 дней с выбором окончания периода и переходом к предыдущему/следующему периоду. Нажмите на столбец дня: длительность, количество сессий, средняя длительность и временные интервалы. Среднее за период включает дни без записей. Это статистика записанного сна, без оценки возрастных норм.
- Завершённый сон делится по местной полуночи с учётом часового пояса и переходов на летнее время. Пересечения записей объединяются, чтобы не удваивать сон. Сессии и среднее выбранного дня считаются по объединённым отрезкам внутри этого дня; сон через полночь участвует в обоих днях.
- Раздел «Прикорм»: поиск продуктов, первая и последняя даты, количество записей, история количества и реакций. Названия объединяются без учёта регистра и лишних пробелов; синонимы автоматически не определяются. История строится из дневника, поэтому исправление или удаление события обновляет её.
- CSV всей истории или выбранного дня через системный выбор файла. UTF-8 с BOM, разделитель `;`, даты со смещением часового пояса, экранирование кавычек и переводов строк; потенциальные формулы в текстовых полях нейтрализуются апострофом. CSV предназначен для таблиц, импорт и резервное восстановление — через JSON. Дневной экспорт, как и раньше, содержит события по дню начала.
- Формат JSON и схема базы не изменились: существующая история сохраняется при обновлении приложения с совместимым ключом подписи.

Следующие этапы для локального приложения: настраиваемые напоминания и фильтры ленты по типу события. Сервер и совместный доступ не требуются.

## Скачать APK с GitHub

Готовые APK публикуются в [Releases](https://github.com/konovar68/Baby-s-check/releases). Откройте последний релиз и в разделе **Assets** скачайте **baby-check.apk** — это установщик, а не архив исходников. Разрешите установку из выбранного браузера, если Android попросит.

Сборки каждого изменения: [Actions → Android APK](https://github.com/konovar68/Baby-s-check/actions/workflows/android.yml). Откройте успешную сборку и скачайте `baby-check-apk` в разделе **Artifacts** (нужен вход в GitHub). Этот вариант скачивается ZIP-архивом: извлеките `baby-check.apk`. Артефакты хранятся 30 дней, отчёты — 14 дней.

GitHub Actions собирает приложение, запускает модульные тесты и Android Lint. Экранные тесты запускаются отдельно на Android-устройстве командой `./gradlew connectedDebugAndroidTest`. Публикация тега `v*` дополнительно создаёт релиз с APK и SHA-256. Сборку можно запустить вручную через **Run workflow**.

Это debug-сборки: ключ подписи GitHub runner может меняться между сборками. Перед установкой версии с другим ключом выгрузите JSON; Android может потребовать удалить старую установку. Для обновлений без переустановки следующим шагом нужно настроить постоянный ключ подписи в GitHub Secrets.

## Сборка

Открыть проект в Android Studio с поддержкой AGP 8.7.3, установить SDK 35. JDK 17 или 21, Gradle 8.9 (wrapper включён).

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

SDK задаётся через `ANDROID_HOME` или локальный `local.properties` (`sdk.dir=...`, не коммитится). APK: `app/build/outputs/apk/debug/app-debug.apk`.

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Debug APK подходит для знакомства и тестирования. Для распространения потребуется отдельный release-ключ подписи, который нельзя хранить в Git.

## Проверка на устройстве

1. Задать профиль, добавить каждый тип события, в том числе сон через полночь и дробные измерения с запятой.
2. Запустить таймер, закрыть и открыть приложение, завершить: должна появиться одна запись.
3. Исправить запись, отменить удаление, затем подтвердить удаление другой записи.
4. Выгрузить всё и день. Импортировать тот же файл повторно: без новых записей.
5. Изменить запись на телефоне, загрузить старый файл сначала без обновления (изменение остаётся), затем с обновлением (возвращается версия из файла).
6. Выгрузить копию до импорта и проверить возможность восстановления через обычный импорт.
7. Загрузить повреждённый JSON: сообщение об ошибке, база не меняется.
8. Открыть «Графики», переключить 7/30 дней, выбрать день со сном через полночь и проверить обе части; проверить пересекающиеся записи и дни без сна.
9. В разделе «Прикорм» найти продукт, раскрыть кормления и проверить сохранённые реакции.
10. Выгрузить CSV и открыть в таблице: проверить кириллицу, единицы, заметку с кавычками/переводом строки. JSON по-прежнему используется для восстановления.
11. Перезапустить телефон и проверить сохранение истории. Проверить выбор даты, графики и работу без сети.

## Ограничения первой версии

Нет синхронизации, напоминаний, нескольких детей, PDF и медицинских рекомендаций. Файл JSON не зашифрован: выбирайте защищённое место хранения. Удаление приложения удаляет базу и внутреннюю резервную копию — заранее выгрузите данные. Графики показывают собственные измерения, а не нормативные кривые развития.
